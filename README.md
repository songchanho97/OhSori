📢 서비스 소개

현대인들은 정보의 홍수 속에서 과도한 뉴스량과 편향성으로 인해 피로감을 느끼고 있습니다. **'Oh! 소리'**는 흩어진 기사들을 한 흐름으로 묶어, 사용자가 원하는 이슈를 다양한 시선으로 압축해 들려주는 새로운 뉴스 소비 문법을 제안합니다. 귀로 따라가기만 하면 되는, 나만을 위한 AI 팟캐스트 스튜디오입니다.

💡 기획 배경 (Why Oh! Sori?)

뉴스 피로도 증가

과도한 뉴스량과 편향성으로 인한 피로감 누적

소비 패턴의 변화

텔레비전, 인터넷 등 전통적 뉴스 소비는 감소하는 반면, '읽기 부담'을 덜어주는 오디오 콘텐츠(팟캐스트) 수요는 지속적으로 증가

멀티태스킹의 필요성

바쁜 현대인들이 상황 제약 없이 뉴스를 접할 수 있는 새로운 방식 필요

🌟 핵심 기능 (Key Features)

1. 🎯 사용자 맞춤형 뉴스 팟캐스트 생성

카테고리 & 검색어: 정치, 경제, 사회 등 카테고리 선택 및 관심 키워드(예: '러시아 우크라이나 전쟁') 직접 입력

분위기 (Mood): 차분한 / 신나는 / 전문적인

언어 (Language): 한국어 / 영어 / 일본어 / 중국어 지원으로 다문화 및 글로벌 환경 대응

2. ⚖️ 입체적인 뉴스 모드 선택

팩트 브리핑 모드: 주관적 의견은 걷어내고 객관적 사실(Fact)만을 빠르게 파악하고자 할 때 제공

균형 토의 모드: 하나의 이슈에 대해 뉴스 속 여러 관점들을 다각도로 입체성 있게 이해하고자 할 때 제공

👥 타겟 페르소나 (Target Audience)

| 페르소나 | 상황 및 니즈 | 맞춤 설정 예시 |
| 취업준비생 | 면접 대비를 위해 사회 이슈를 다각도로 정리하고 싶음 | 차분한 + 균형 토의 + 한국어 |
| 해외영업 팀장 | 해외 파트너 미팅 전 불필요한 해설 없이 빠른 팩트체크 필요 | 전문적인 + 팩트 브리핑 + 영어/일본어 |
| 전업 주부 | 아이를 돌보며 무겁지 않은 생활 뉴스를 균형 있게 청취하고 싶음 | 신나는 + 균형 토의 + 한국어 |

⚙️ 아키텍처 및 기술 스택 (Architecture & Tech Stack)

1. 데이터 수집 및 처리 : BIGKinds

한국언론진흥재단이 제공하는 공신력 있는 빅카인즈(BIGKinds) 뉴스 데이터 활용 (일일 약 20,000건)

기사 수집 후 태그 제거 및 본문 병합 전처리 진행

2. 대본 생성 : OpenAI (GPT-4o API)

PodAgent 논문에 기반한 3단계 AI 에이전트 프레임워크 적용

호스트 에이전트: 뉴스 기사를 바탕으로 인터뷰 질문 작성

게스트 에이전트: 질문에 대한 맞춤형 답변 작성

작가 에이전트: 질문과 답변을 엮어 조건에 맞는 최종 대본 완성

3. 음성 생성 : ElevenLabs API

부드러운 중년 남성, 내레이션 특화 젊은 여성, 밝은 청년 등 대본 분위기에 맞는 고품질 AI 음성 합성

📈 비즈니스 임팩트 및 기대 효과

💰 압도적인 제작 비용 절감

기존 팟캐스트 제작 방식 대비 비용을 혁신적으로 절감하여 무한한 콘텐츠 확장이 가능합니다. (5분 분량 기준)

기존 방식: 약 120,000원 (작가, 성우, 편집, 녹음실 대여 등)

Oh! 소리: 약 380원 (GPT-4o API 약 130원 + ElevenLabs API 약 250원)

🤝 사회적 포용성 확대

정보 접근성 향상: 직관적인 UI와 오디오 포맷으로 노인, 시각장애인도 쉽게 이용 가능

글로벌/다문화 포용: 다국어 음성 뉴스 제공으로 언어 장벽 해소 및 국내 이슈 이해도 증진

🚀 확장 가능한 서비스 생태계

향후 대형 포털(예: 네이버 뉴스) 내 'OH!Sori 팟캐스트 듣기' 버튼 연동 가능

개인 청취 이력 기반 맞춤 추천 및 실시간 인기 팟캐스트 차트 제공
